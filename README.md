## Julkaisu GitHub Pagesiin
1. GitHubissa: luo organisaatio **crazylaserguystudio** ja sinne repo **crazylaserguystudio.github.io** (julkinen).
2. Lataa tämän kansion sisältö repoon (Add file → Upload files) ja Commit.
3. Repo → Settings → Pages → Source: *Deploy from a branch*, branch **main**, kansio **/ (root)**.
4. Custom domain: **crazylaserguystudio.fi** (CNAME-tiedosto on jo mukana) → Enforce HTTPS kun se aktivoituu.
5. DNS (Domainhotelli) – Claude tekee nämä:
   - A @ → 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 (poistetaan vanha A 31.217.196.149)
   - CNAME www → crazylaserguystudio.github.io.
   - Postin tietueita (MX, SPF, autodiscover, MS=) EI kosketa.
